Before you write

A few useful answers

Do you accept story pitches?

Yes. Send a two-paragraph pitch with the place, the specific angle and what you can report first-hand. Please mention any local collaborators who should be credited.

Can I republish a story?

Write to us with the story URL and where it would appear. We consider requests case by case and ask for a visible link back to the original.

I spotted a factual error.

Thank you for telling us. Include the sentence and the source for the correction. Corrections are reviewed and, when confirmed, published transparently.

How are photographs credited?

Each cover credit names the photographer and links to the source. If you believe an image is misattributed, contact us and we will investigate promptly.

How do I sign in with Google, WeChat or my phone?

Use the sign-in buttons on the account page. Google and WeChat open their secure sign-in screens; phone sign-in sends a six-digit code by SMS. If a provider is not configured on this installation, use email and password or contact us.

I did not receive a phone code.

Check the number and try again after a minute. In local development the code is printed in the server console instead of being sent by SMS. For production, the site owner must configure an SMS provider.
