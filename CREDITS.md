# Credits

Himalaya Connect is possible because a lot of people shared their work. This file
records the photography, films, fonts, map data, software and reference material
used in the project. If you reuse anything from this repository, check the licence
listed for that item rather than assuming the project licence covers it.

## Project content

The code is MIT-licensed. Original editorial text and project-created illustrations
are licensed under CC BY 4.0; if you reuse them, credit Himalaya Connect and link
back to the repository. The seed story personas are fictional editorial voices.
